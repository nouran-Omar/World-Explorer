## 🌍 World Explorer – Travel Website

**World Explorer** is a modern and fully responsive travel website designed to inspire users to explore breathtaking destinations across the globe.  
This project focuses on **clean design**, **user-friendly navigation**, and **immersive visuals** to give visitors a smooth browsing experience.

### ✨ **Key Features**
- **Modern UI/UX Design** – Clean, attractive layout with a travel-inspired theme.
- **Responsive Navbar** – Smooth scrolling and navigation for all screen sizes.
- **Hero Section** – Engaging welcome banner with action buttons.
- **About Section** – Highlights the mission and purpose of the website.
- **Top Destinations** – Showcases stunning travel spots.
- **Gallery** – A beautifully organized photo grid with curated travel images.
- **Contact Section** – Includes contact details for inquiries.
- **Footer with Quick Info** – Hours, contact details, and travel tips.

---

### 🛠 **Technologies Used**
- **HTML5** – Structure and content of the website.
- **CSS3** – Custom styling with gradients and animations.
- **Bootstrap 5** – Responsive design and grid system.
- **Google Fonts** – Beautiful, modern typography.
- **FontAwesome Icons** – Sleek icons for UI elements.

---

### 🎯 **What I Learned**
- Creating **responsive layouts** with Bootstrap Grid.
- Designing **modern landing pages** with smooth scrolling.
- Building **section-based single-page websites**.
- Organizing a project structure with separate **CSS and image folders**.
